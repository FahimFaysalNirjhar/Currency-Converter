# 💱 Currency Converter Web App

A simple and responsive Currency Converter web application built using **HTML, CSS, and JavaScript**.  
It allows users to convert amounts between different currencies using real-time exchange rates from a free public API.

---

## 🚀 Features

- Convert between **200+ world currencies**
- Live exchange rates (updated daily)
- Automatic flag update based on selected currency
- Simple and clean UI
- Mobile responsive
- No backend required — 100% frontend

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Font Awesome (for icons)
- Free Currency API by fawazahmed0
